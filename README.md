# Suryansh Dwivedi — Full Stack Developer Portfolio

A responsive React + Vite portfolio with a dark / electric-blue theme and GSAP animations.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Important: personalize before publishing

1. In `src/components/Contact.jsx`, replace `YOUR_EMAIL@example.com` with your real email.
2. In `src/data.js`, add your actual GitHub repository URLs and live demo URLs to each project (`repo` and `demo`).
3. Review each project description and keep only features you personally implemented.
4. Add your real LinkedIn and GitHub profile URLs in `src/components/Contact.jsx`.
5. Add a real resume PDF to `public/resume.pdf` and add a resume link if you want to show it.
6. Review the skills list and remove anything you cannot comfortably discuss in an interview.

No fake company experience, certifications, ratings, or achievement claims have been added.
